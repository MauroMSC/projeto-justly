# Justly

Site institucional desenvolvido com HTML e CSS, com foco na apresentação visual, organização de conteúdo e estruturação de páginas.

## Tecnologias utilizadas

- HTML5
- CSS3

## Sobre o projeto

O Justly é um projeto desenvolvido para praticar e aplicar conhecimentos de desenvolvimento Front-end, trabalhando com estruturação de páginas, estilização e organização de elementos visuais.

## Como visualizar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
